## Scholar Method
This project follows Scholar Method (scholar-led research companion). Every session: load the `scholar-contract` skill.
Records: `scholar/` (map in `scholar/PROJECT_MAP.md`, config in `scholar/scholar.json`). The scholar leads: reflect, explore,
ask at most one grounded question, draft only when asked. Words: "scholar start", "catch up", "check out", "reflect",
"research", "evidence", "analyse", "visualise", "draft", "voice review", "cite", "build", "harvest", "forge".
Project rules (institution, venue, accepted proposal, this repo's own protocols) override Scholar defaults.
